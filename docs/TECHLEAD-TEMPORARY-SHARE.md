# 临时分享任务

Agent 和控制器继续在原机器工作。分享网关只转发选定任务的当前快照和
inbox；Cloudflare Quick Tunnel 为该网关分配临时 HTTPS 入口。
分享访问令牌与本机操作员令牌独立。手机端的分享权限不包含 Start、规划、
创建任务、节点登记或执行控制。

## 使用前提

- 已有运行中的 Sisyfus Tech Lead 控制台及确定的 mission_id。
- Python 3.11+；开发源码通过 PYTHONPATH 或已安装版本可见。
- 公网分享需已有 cloudflared；本地检查使用 --local-only。
- 操作员将本机控制台 token 放在当前用户拥有的独立普通文件中：权限0600、
  单链接、非symlink，至多4096字节。不要把 token 直接放进命令参数。
- runtime-directory 必须是全新绝对路径，其父目录无symlink。启动创建该
  独占目录及私密 access.json；重跑使用不同目录，旧证据保留。

## 启动

下面的 PORT、MISSION_ID 和路径由操作员填写，命令本身不执行任务：

```sh
PYTHONPATH=/ABS/SISYFUS/src python -m sisyfus.workers.lead_cli share \
  --console-origin http://127.0.0.1:PORT \
  --operator-token-file /ABS/operator-token.private \
  --mission-id MISSION_ID \
  --runtime-directory /ABS/NEW-SHARE-RUN \
  --allow-messages \
  --report /ABS/SELECTED-REPORT.html
```

- 默认仅查看；--allow-messages 才开放已有 /btw 与补充资料通道。
- --report 可省略。指定的 HTML 是固定版本文档，不冒充任务当前结论。
- --local-only 启动本机分享页，不建立公网隧道。
- --cloudflared 指定已有可执行文件；--startup-timeout 配置有限启动等待。
- 安装本开发版后，顶层入口 sisyfus.entrypoint 支持 sisyfus techlead share。
  本机保留的 v0.7.0 启动脚本仍指向旧 sisyfus.cli；源码运行请使用上面的
  python -m sisyfus.workers.lead_cli share，不覆盖旧安装。

## 密码登录（本轮新增，公网使用此模式）

先由操作员在本机创建一个全新的密码校验文件。交互输入两遍密码；终端隐藏
输入，命令参数和聊天记录中都没有明文。至少12个字符，可使用中文或空格，
至多128个字符。文件只保留随机盐和固定参数的 scrypt 校验值，权限0600。

```sh
PYTHONPATH=/ABS/SISYFUS/src python -m sisyfus.workers.share_password \
  --output /ABS/NEW-SHARE-PASSWORD.json
```

随后在前面的 share 命令中增加：

```sh
  --password-file /ABS/NEW-SHARE-PASSWORD.json
```

密码模式的 access.json 只保存无片段的入口。把这个普通 HTTPS 地址交给
访问者，在手机／另一台电脑打开时会先显示“访问密码”。本机验证通过后
签发该设备独立的临时会话；直接读取图、任务、消息或报告接口也受校验，
不是仅靠前端隐藏页面。刷新或换设备重新输入密码。

- 密码登录经 Cloudflare 的 HTTPS 入口传送到本机网关校验，属于 Cloudflare
  代理流量；该密码应专用于这次分享，不要复用交易所或其他账户密码。
- 每个会话最长8小时，只在页面内存中保留；没有 cookie、浏览器持久存储
  或地址栏密码／会话。退出先清空页面，再撤销本设备会话；其他设备不受影响。
- 全部设备共用每60秒5次登录尝试限额，超过时明确提示；同一时刻最多1次
  密码派生，避免并发占满机器。最多64个同时有效会话。
- 停止分享撤销全部会话。换密码使用新的校验文件并重新启动分享；
  旧校验文件和运行证据保留，旧运行停止后旧会话失效。
- 校验文件格式、权限或身份错误在开放入口前报错。原操作员 token
  不进入密码登录链路，也没有执行权限转移。

兼容模式：省略 --password-file 时保留已有独立访问令牌入口。仅令牌模式的
私密 access.json 包含 /#token=...；页面消费片段后清空地址栏。密码模式拒绝
该静态令牌及原操作员 token，兼容模式链接不适用于密码模式入口。

## 网页内容

图、进度和工程结果消费同一次控制台快照，保留真实0与false。刷新失败显示
失联／过期状态，不用空列表或旧成功冒充新结果。每5秒轮询，无重叠请求。
单独附带的报告有自己的固定hash，变化时显式报错。

发消息只进入当前任务已有inbox：收到、绑定及native接受是不同状态。
消息发送出现未知结果时，先查原request_id的收据；不自动重发。

## 生命周期与边界

- HOST_ASSIGNED 只表示拿到域名；CONNECTED 需实际隧道连接事件，仍不是
  手机／外部浏览器验收。公网可用性需另做实际 HTTPS 检查。
- Ctrl-C 只停止分享网关和它拥有的 cloudflared 进程组，原控制台／任务继续。
- 隧道失败、退出或启动超时撤销分享访问并保留诊断；不自动重启未知调用。
- 新隔离HOME/config不读取旧 .cloudflared 配置，不改变原有 launch agents；
  日志有界，全部旧文件保留，不做永久清理。
- Quick Tunnel 无可用性保证，重新创建时地址会变化，机器与进程需在线。
  当前不使用 SSE；长期入口可另设固定域名 Tunnel 与访问策略。

此接口面向一项 mission，其中可以包含多个任务与多个节点；多机 Agent 的
通信／执行仍使用原控制器协议，分享隧道不替代节点凭据和任务同步。
发布源码、浏览器模拟、真实公网、实体手机、双机与 RSI 晋升分别验收。

官方参考：[Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)。
安装的 cloudflared 版本可能早于在线文档的新参数；本接口以已有客户端与
应用自己的独立分享令牌为基础，不依赖新 --allowed-mail 参数。
